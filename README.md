# 🎮 Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using Python.

## 📌 About the Project

This is a beginner-friendly Python project where the player competes against the computer. The computer randomly selects Rock, Paper, or Scissors, and the winner is decided based on the game rules.

## ✨ Features

- Player vs Computer gameplay
- Random computer choices
- Win, Lose, and Tie detection
- Simple command-line interface
- Built using Python

## 🛠️ Technologies Used

- Python
- Random module

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/shaikmadiha2007/rock-paper-scissors-python.git
   ```

2. Navigate to the project folder:

   ```bash
   cd rock-paper-scissors-python
   ```

3. Run the game:

   ```bash
   python rps.py
   ```
